Prompt Engineering adalah teknik penambahan konteks pada sebuah prompt (instruksi atau masukan yang diberikan kepada model AI) agar sistem dapat memahami keinginan kita secara maksimal. Ketika memberikan instruksi kepada AI, penting untuk menyertakan konteks dan batasan yang jelas guna mencegah terjadinya AI Hallucination, yaitu kondisi di mana AI memberikan informasi yang tidak akurat namun terlihat meyakinkan. Struktur yang baik dalam menyusun prompt AI umumnya mencakup empat elemen penting, yaitu role (profil), task (tugas), context (konteks), dan format. Keuntungan dari penerapan prompt engineering ini antara lain dapat meningkatkan performa respons model AI, mengurangi bias, meningkatkan kontrol serta controllability, serta memberikan pengalaman interaksi yang jauh lebih baik.

Selain pemahaman mengenai AI, dalam dunia pengembangan perangkat lunak juga dikenal istilah Git, yaitu sebuah sistem kontrol versi (version control system) yang berfungsi untuk melacak siapa, kapan, dan apa saja perubahan yang telah dilakukan pada suatu file dari waktu ke waktu. Dalam praktiknya, sering kali muncul pertanyaan mengenai perbedaan antara Git dan GitHub. Secara mendasar, Git adalah perangkat lunak version control system yang berjalan secara lokal di komputer untuk mencatat riwayat perubahan kode, sedangkan GitHub adalah platform berbasis cloud yang berfungsi sebagai tempat penyimpanan online untuk repositori Git guna memudahkan kolaborasi tim secara jarak jauh, melakukan backup kode, serta melakukan manajemen proyek.
