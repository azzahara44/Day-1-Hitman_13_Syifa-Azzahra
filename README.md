## 🌻 Prompt Engineering
**Pengertian:** Prompt Engineering adalah teknik penambahan konteks pada sebuah prompt (instruksi atau masukan yang diberikan kepada model AI) agar sistem dapat memahami keinginan kita secara maksimal. Ketika memberikan instruksi kepada AI, penting untuk menyertakan konteks dan batasan yang jelas guna mencegah terjadinya AI Hallucination, yaitu kondisi di mana AI memberikan informasi yang tidak akurat namun terlihat meyakinkan. Struktur yang baik dalam menyusun prompt AI umumnya mencakup empat elemen penting, yaitu role (profil), task (tugas), context (konteks), dan format. Keuntungan dari penerapan prompt engineering ini antara lain dapat meningkatkan performa respons model AI, mengurangi bias, meningkatkan kontrol serta controllability, serta memberikan pengalaman interaksi yang jauh lebih baik.

**Tips menulis prompt:** 
1. Gunakan kata kerja aksi untuk menyatakan hasil yang diinginkan.
2. Tentukan panjang dan format output.
3. Sebutkan target audiens.
4. Sertakan fakta dan data yang relevan.
5. Rujuk sumber atau dokumen tertentu.
6. Definisikan istilah dan konsep kunci.

**Manfaat prompt yang baik:** 
1. Meningkatkan performa model AI
2. Mengurangi bias dan respons yang offensive
3. Meningkatkan kontrol dan prediktabilitas
4. Memberikan pengalaman yang lebih baik

## 🌻 Git dan GitHub
**Pengertian:** Selain pemahaman mengenai AI, dalam dunia pengembangan perangkat lunak juga dikenal istilah Git, yaitu sebuah sistem kontrol versi (version control system) yang berfungsi untuk melacak siapa, kapan, dan apa saja perubahan yang telah dilakukan pada suatu file dari waktu ke waktu. Dalam praktiknya, sering kali muncul pertanyaan mengenai perbedaan antara Git dan GitHub. Secara mendasar, Git adalah perangkat lunak version control system yang berjalan secara lokal di komputer untuk mencatat riwayat perubahan kode, sedangkan GitHub adalah platform berbasis cloud yang berfungsi sebagai tempat penyimpanan online untuk repositori Git guna memudahkan kolaborasi tim secara jarak jauh, melakukan backup kode, serta melakukan manajemen proyek.

**3 area utama Git workflow:** 
1. Working directory/tree: salinan satu versi proyek yang sedang kamu kerjakan. File diambil dari database Git lalu ditempatkan di komputer agar bisa dipakai atau diubah.
2. Staging area (index): file di dalam direktori Git yang menyimpan informasi tentang perubahan apa saja yang akan masuk ke commit berikutnya.
3. git directory (repository): tempat Git menyimpan metadata dan object database proyek. Ini bagian terpenting Git karena berisi seluruh informasi yang dibutuhkan untuk mengelola proyek, dan inilah yang disalin saat kamu clone repository.

**Git setup:** 
1. Install Git (cari di Google “install git”).
2. Pilih versi sesuai device.
3. Buka terminal/cmd, cek dengan git --version.
4. Atur identitas Git:
   git config --global user.name "Your Name"
   git config --global user.email "your-email@example.com"
5. Cek konfigurasi: git config --global --list

**VS Code setup:**
1. Install VS Code, lalu buka.
2. Tekan Cmd+Shift+P (Mac) / Ctrl+Shift+P (Windows).
3. Cari “Shell Command: Install ‘code’ command in PATH”.
4. Di terminal, cek dengan code --version.
